# 📚 AI Study Buddy

AI Study Buddy is an AI-powered learning assistant that helps students understand topics quickly. It uses Google Gemini AI to generate summaries, quizzes, flashcards, and answers from study material.

## 🚀 Features
- Summarizes study notes
- Generates flashcards
- Creates quizzes
- Answers questions

## 🛠 Technologies Used
- Python
- Streamlit
- Google Gemini API
- Natural Language Processing (NLP)

## ⚙️ How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Create `.env` file and add:
GOOGLE_API_KEY=your_api_key_here

3. Run the app:
streamlit run app.py
